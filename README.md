# sezeresim.com

Personal site and blog built with Next.js 16 (App Router), React 19, Tailwind CSS v4, Contentlayer2 (MDX) and Motion.

## Scripts

```bash
yarn dev        # build content and start the dev server
yarn build      # build content and the production bundle (also generates the sitemap)
yarn lint       # eslint
yarn typecheck  # tsc
yarn test       # jest
```

Posts live in `posts/*.mdx`. Site copy, social links and projects are in `src/constants/index.tsx`.
